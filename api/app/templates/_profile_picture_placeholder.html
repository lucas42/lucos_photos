{# Shared "no profile picture" placeholder. Set these context vars immediately before each include (reset both every time — Jinja set-scoping inside a loop body would otherwise leak a value from a previous iteration or template): pfp_extra_class – additional CSS class for sizing, e.g. "person-profile-picture-large" (use none/"" if the base 100px placeholder size is already correct). pfp_aria_label – accessible name for the placeholder, e.g. "No profile picture". Set to none when a visible sibling (a name heading/span) already announces the person, so the link isn't announced twice.
